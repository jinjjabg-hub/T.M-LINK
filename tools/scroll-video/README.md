# 스크롤 홍보 영상 만들기

비즈홈(웹페이지) 하나를 **폰 화면에서 위→아래로 스크롤되는 영상**으로 바꿔 줍니다.
인스타 릴스·피드, 카카오톡 프로필에 바로 쓸 수 있는 3가지 크기를 한 번에 만듭니다.

## 왜 만드나 (목적)
- 비즈홈은 링크로 보여주지만, **인스타·카톡 프로필에는 링크 대신 "움직이는 그림"이 필요**합니다.
- 영상으로 만들면 "길고 알찬 페이지가 있다"는 인상을 한눈에 주고, 보는 사람이 링크를 누르게 만듭니다.
- 프리미엄(25만원) 고객에게 "내 비즈홈 홍보 영상 세트"로 줄 수 있습니다. (고객 이름만 바꿔 같은 방법으로 반복 제작)

## 사용법 (한 줄)
```bash
node make-scroll-video.mjs \
  --url "https://jinjjabg-hub.github.io/BNI-PIONEER-cards/송승훈/" \
  --name 송승훈 --role "T.M LINK 대표" --tags "앱개발,웹제작" \
  --out ./out
```
끝나면 `./out` 에 영상이 생깁니다. (약 3분)

| 파일 | 어디에 쓰나 | 크기 | 길이 |
|---|---|---|---|
| `reels.mp4` | 인스타 릴스·스토리 | 1080×1920 (9:16) | 30초 |
| `feed.mp4` | 인스타 피드 | 1080×1350 (4:5) | 30초 |
| `kakao.mp4` / `kakao.png` | 카카오톡 프로필 영상 / 사진 | 1080×1080 (1:1) | 10초 |

- `--name` 을 주지 않으면 카톡용(kakao)은 건너뜁니다.
- 일부만 만들려면 `--presets reels,kakao`

## 옵션
| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--url` | 영상으로 만들 비즈홈 주소 | (필수, 또는 `--image`) |
| `--image` | 이미 캡처한 긴 이미지 파일(폭 860px 권장) | |
| `--out` | 결과 폴더 | `./out` |
| `--name` `--role` `--tags` | 카톡용 이름 / 직함 / 분야(쉼표로 여러 개) | |
| `--title` | 릴스·피드 제목(`\|` 가 줄바꿈) | 명함보다 깊고,\|홈페이지보다 가볍게 |
| `--kicker` `--footer` | 제목 위 작은 글 / 아래 주소 | |
| `--bg1` `--bg2` `--bg3` | 배경 그라데이션 3색 | 파란색 계열 |
| `--offline` | 같은 주소 외 요청 차단 (인터넷이 막힌 환경에서 로컬 서버를 캡처할 때) | |

## 필요한 것
`node` · `playwright`(+chromium) · `ffmpeg` · ImageMagick(`convert`, `identify`)
playwright 위치가 다르면 `PLAYWRIGHT_PATH=/경로/playwright` 로 알려 주세요.

## 만든 방법 (원리)
1. **캡처**: 비즈홈을 폰 폭(430px, 2배 선명도)으로 열어 **끝까지 한 장의 긴 이미지**로 찍습니다.
   - 늦게 뜨는 그림이 빠지지 않도록 끝까지 천천히 내려갔다 올라옵니다.
   - 화면에 떠 있는 고정 버튼("카드 현황 보기" 등)은 긴 이미지 한가운데 찍히므로 숨깁니다. (소식판 배너는 유지)
2. **틀 만들기**: 크기별로 그림 2장을 만듭니다.
   - `배경`: 파란 그라데이션 + 글자 + 폰 그림자
   - `폰 테두리`: 화면 부분이 **투명하게 뚫린** 검은 테두리 (노치 포함)
3. **합성(ffmpeg)**: `배경` → `긴 이미지를 시간에 따라 위에서 아래로 잘라 보여주는 화면` → `폰 테두리` 순서로 겹칩니다.
   - 처음 1.5초 멈춤 → 일정한 속도로 스크롤 → 끝에서 2초 멈춤 (카톡용은 0.8초 / 1초)
   - H.264, 30fps, 소리 없음 → 인스타·카톡 모두 재생됨

## 크기별 설계 이유 (데이터)
- **릴스**: 인스타 위·아래 약 250px / 340px는 앱 화면이 가립니다 → 제목은 위쪽 안전 구역 아래(y≈280~)에, 폰은 y 480~1520에 배치.
- **스크롤 속도**: 릴스 약 240px/초, 피드 220, 카톡 563(프로필은 읽는 용도가 아니라 "긴 페이지" 인상용).
- **카톡 프로필**: 정사각형으로 올라가고 목록에서는 동그랗거나 둥근 사각으로 잘립니다 → 폰을 한가운데 쪽에, 글자는 왼쪽 큰 글씨로. 영상 길이·용량 제한은 앱 버전에 따라 달라 프로필 편집 화면의 안내를 따르세요.

## 알아둘 점
- 영상은 **만든 시점의 비즈홈**입니다. 비즈홈을 고치면 영상을 다시 만들어야 합니다.
- 한글 글꼴(Noto Sans CJK KR 등)이 없는 컴퓨터에서는 글자 모양이 다르게 나올 수 있습니다.
- 소식판 배너도 영상에 들어가므로, 시험 글이 남아 있으면 먼저 지우세요.
- 이 폴더를 새로 만든 대화에서 찾을 수 있도록 저장소 루트의 `CLAUDE.md` 에 안내를 적어 두었습니다.
