# 비즈홈 홍보 영상 만들기 (카톡 프로필 · 인스타 릴스 · 인스타 피드)

비즈홈(웹페이지)을 **폰 화면에서 위→아래로 스크롤되는 영상**으로 바꿉니다.
고객이 자기 카톡 프로필과 인스타에 올릴 수 있도록, **고객 한 명 한 명의 영상**을 만들어 드리는 도구입니다.

## 왜 만드나 (목적)
- 비즈홈은 링크로 건네지만, **카톡 프로필·인스타에는 링크 대신 "움직이는 화면"** 이 필요합니다.
- 영상으로 만들면 "길고 알찬 비즈홈이 있다"는 인상을 바로 주고, 보는 사람이 링크를 누르게 만듭니다.
- 영상의 주인공은 **고객 본인**입니다. 이름·회사(직함)·비즈홈 주소가 들어가고, 배경색도 **그 고객 비즈홈의 대표 색**입니다. TM LINK 표시는 넣지 않습니다.

## 가장 쉬운 방법 (고객 한 명)
```bash
node make-scroll-video.mjs --url "고객 비즈홈 주소" --name 고객이름 --role "회사 또는 직함" --out ./out
```
(분야 표시를 넣으려면 `--tags "앱개발,웹제작"`)  → `./out` 에 3종이 생깁니다. 약 1~2분.

| 파일 | 어디에 쓰나 | 크기 | 길이 |
|---|---|---|---|
| `kakao.mp4` / `kakao.png` | 카카오톡 프로필 영상 / 같은 디자인 사진 | 1080×1080 (1:1) | 10초 (페이지 앞부분) |
| `reels.mp4` | 인스타 릴스·스토리 | 1080×1920 (9:16) | 페이지 길이에 맞춰 12~60초 |
| `feed.mp4` | 인스타 피드 | 1080×1350 (4:5) | 페이지 길이에 맞춰 12~60초 |

## 고객 여러 명을 한꺼번에 (전체 고객)
```bash
# 1) 대상 목록 초안 만들기 (이름·직함을 카드 <title> 에서 자동으로 뽑음)
python3 draft-customers.py \
   --repo BNI-PIONEER-cards=/경로/bni-pioneer-cards --repo NAMECARD=/경로/namecard --repo bni-giants=/경로/bni-giants \
   --exclude 만들지않을폴더1,폴더2 --out customers.json
# 2) customers.json 에서 check:true 인 줄(폴더 이름과 제목의 이름이 다른 고객)을 확인해 고치고 check 줄 삭제
# 3) 카톡 프로필 먼저 → 인스타용
python3 batch.py --list customers.json --out ./out --presets kakao --workers 3
python3 batch.py --list customers.json --out ./out --presets reels,feed --workers 2
```
- 인터넷이 막힌 환경(Claude Code 클라우드 등)에서는 카드 레포를 받아 `python3 -m http.server 포트` 로 띄우고
  `--map https://jinjjabg-hub.github.io/레포이름/=http://localhost:포트/ --offline` 을 `batch.py` 에 붙입니다.
- **고객 목록(customers.json)은 공개 저장소에 올리지 않습니다.** (목록은 비공개 저장소 `tmlink-agents`의 `biz/common/scroll-video.md`에 있음)
- 시간(4코어 기준): 카톡 38명 약 8분, 릴스+피드 38명 약 50분.

## 영상에 들어가는 것 / 자동으로 정해지는 것
| 항목 | 내용 |
|---|---|
| 이름·회사(직함) | `--name`, `--role`. 릴스·피드는 위쪽 제목, 카톡은 왼쪽 큰 글씨 |
| 아래 주소 | 고객 비즈홈 주소 (`--footer` 로 바꿈) |
| **배경색(대표 색)** | 비즈홈 **페이지 배경색**을 읽어 그라데이션으로 만듦. 너무 밝은 카드는 포인트색을 바탕으로, 거의 검정이면 포인트색을 살짝 섞은 은은한 빛 |
| **글씨 포인트색** | 카드 디자인의 `--gold2/--gold/--accent` 등. 바탕과 비슷하거나 검정이면 밝게 보정 |
| 직접 정하기 | `--color "#15613a" --accent "#e8c877"` |
| **스크롤 속도** | 모든 영상 같은 속도: **폰 화면 폭의 42%/초** (릴스 약 227px/초). 페이지가 길면 릴스·피드 영상이 길어지고, 카톡(10초 고정)은 앞부분만 보여 줌 |

## 만든 방법 (원리)
1. **캡처**: 비즈홈을 폰 폭(430px, 2배 선명도)으로 열어 끝까지 **한 장의 긴 이미지**로 찍는다.
   - 늦게 뜨는 그림이 빠지지 않게 끝까지 천천히 내려갔다 올라온다.
   - 화면에 떠 있는 고정 버튼("카드 현황 보기" 등)은 긴 이미지 한가운데 찍히므로 숨긴다. (소식판 배너는 유지)
   - 이때 페이지 배경색과 `--gold` 같은 색 변수도 함께 읽는다.
2. **틀 그림 2장**: `배경`(그라데이션 + 이름·직함·주소 글자 + 폰 그림자), `폰 테두리`(화면 부분이 투명하게 뚫린 검은 틀).
3. **합성(ffmpeg)**: `배경` → `긴 이미지를 시간에 따라 위에서 아래로 잘라 보여주는 화면` → `폰 테두리` 순서로 겹친다.
   처음에 잠깐 멈췄다가 일정한 속도로 내려가고, 끝에서 다시 멈춘다. H.264, 30fps, 소리 없음.

## 크기별 설계 이유 (데이터)
- **릴스**: 인스타가 위 약 250px, 아래 약 340px을 가린다 → 제목은 위쪽 안전 구역 아래에, 폰은 y 500~1520에 배치.
- **카톡 프로필**: 정사각형 1:1로 올라가고 목록에서는 둥글게 잘린다 → 글자는 왼쪽 큰 글씨, 폰은 오른쪽. 영상 길이·용량 제한은 앱 버전에 따라 달라 프로필 편집 화면의 안내를 따른다. 안 올라가면 `kakao.png` 사진을 쓴다.
- **속도를 하나로 통일한 이유**: 처음엔 영상 길이를 30초로 고정했더니 고객마다 초당 76~399px로 제각각(짧은 페이지는 느리고 긴 페이지는 빠름)이었다. 카톡은 10초에 전체를 훑어 인스타보다 3배 빨랐다. → 속도를 고정하고 길이를 맞추는 방식으로 변경.

## 시행착오 (같은 실수 반복 방지)
- 투명 배경 그림을 만들 때 `body` 배경은 투명 처리에서 사라진다 → 배경은 안쪽 `div` 에 칠한다.
- 한글 폴더 이름은 `git ls-tree` 에서 `\352\271...` 로 깨져 보인다 → `git -c core.quotepath=false` 를 쓴다.
- 오래된 복사본으로 세면 고객 수가 틀린다(10월 초 복사본에는 새 고객이 없었다) → 항상 최신 `main` 을 받아 센다.
- ImageMagick 색 뽑기는 `-format %c histogram:info:-` 처럼 **끝에 `-`** 가 있어야 출력된다.
- 가장 많이 쓰인 색을 고르면 대부분 어두운 배경색이라 "대표 색"이 아니다 → 카드 디자인의 변수(페이지 배경·`--gold`)를 읽는 방식으로 바꿨다.

## 필요한 것 / 알아둘 점
`node`, `playwright`(+chromium), `ffmpeg`, ImageMagick(`convert`, `identify`, `montage`). playwright 위치가 다르면 `PLAYWRIGHT_PATH=/경로/playwright`.
- 영상은 **만든 시점의 비즈홈**입니다. 고객이 크게 고치면 다시 만들어야 합니다. 소식판 시험 글이 남아 있으면 먼저 지우세요.
- 한글 글꼴(Noto Sans CJK KR 등)이 없는 컴퓨터에서는 글자 모양이 달라질 수 있습니다.
- 만든 영상은 고객 이름이 들어가므로 **공개 저장소에 올리지 말고** 카톡·구글 드라이브 링크로 전달합니다.
