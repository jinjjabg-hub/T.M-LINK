# 앱 소개 페이지 만들기 (오토명함·카드북·만두·주주도사)

`/apps/<앱>/index.html` 4장과 `apps.js` 는 **생성물**입니다. 직접 고치지 말고 이 폴더의 원본을 고친 뒤 다시 만드세요.

## 고치는 법
```bash
python3 tools/apps-pages/regen.py      # 저장소 루트에서
```
→ `apps.js` 와 `apps/*/index.html` 이 새로 만들어집니다. (node 필요)

| 파일 | 역할 |
|---|---|
| `content.py` | **앱별 상세 내용**(왜/이용방법/기능/가격/FAQ/함께 쓰면 좋은 서비스) — 한·영·중·일을 `T('한국어','English','中文','日本語')` 로 나란히 적음 |
| `render.js` | 페이지를 그리는 코드(브라우저·Node 공용). 한국어 본문은 정적으로 HTML에 넣고, 언어 바꾸면 브라우저에서 다시 그림 |
| `regen.py` | 위 둘을 합쳐 `apps.js` 와 4개 페이지를 생성 |
| `ac_texts.json` | 오토명함 앱(autocard 레포 `assets/i18n.js`)에서 뽑은 소개 문구 36개 (대표님이 직접 쓴 문구) |

앱의 기본 정보(이름·분류·한 줄 소개·앱 주소·설치 안내)는 `apps.js` 맨 위 `APPS`, `SHEET_UI` 에 있고,
`regen.py` 는 그 부분을 그대로 유지합니다. (이 값은 `apps.js` 를 직접 고치세요.)

## 새 앱 추가하는 법
1. `apps.js` 의 `APPS` 에 항목 추가(앱 주소·아이콘·4개 언어 이름/설명)
2. `content.py` 의 `C` 에 같은 키로 상세 내용 추가 (`visual` 은 `img:경로` / `chat` / `personas`)
3. `regen.py` 의 `colors` 에 **대표 색** 추가 (각 앱의 theme color, 연한 색은 같은 색의 10% 투명)
4. `apps/<키>/index.html` 을 기존 페이지 복사해서 만들고 `regen.py` 실행
5. 홈(`index.html`)의 서비스 카드에 `style="--c:색;--ct:연한색"` 과 링크 추가
