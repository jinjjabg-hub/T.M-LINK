# TM LINK 사이트 AI-SEO 점검 (2026-11-12)

> **왜 하나요?** 요즘 "부산 개인 홈페이지 제작", "디지털 명함 앱 추천"을 ChatGPT·Gemini·네이버 AI 답변·구글 AI 개요에 묻는 사람이 늘고 있습니다.
> 이 답변에 **TM LINK가 근거로 인용되려면** ① 크롤러가 들어올 수 있고 ② 어느 주소가 진짜인지 분명하고 ③ 회사·상품·가격이 기계가 읽는 형태로 적혀 있어야 합니다.

## 우선순위별 문제와 해결

### 🔴 P0 — 지금 AI·검색엔진이 우리를 헷갈려 하는 문제

**1. 대표 주소가 둘이다 (신뢰도 분산)**
- `CNAME` = `tmlink.bizmy.net` (맞춤 도메인이 연결돼 있음)
- 그런데 모든 페이지의 `og:url`·이미지 URL은 `jinjjabg-hub.github.io/T.M-LINK/`
- 결과: 같은 내용이 **두 주소**로 노출 → 링크 점수·AI 인용이 갈라짐.
- **해결:** 대표 주소를 하나로 정하고(추천: 맞춤 도메인 `tmlink.bizmy.net`) 전 페이지에 `<link rel="canonical">` + `og:url` 통일.
  ⚠️ 결정 필요: 카톡 등에 이미 퍼진 github.io 링크는 계속 열리지만, 어느 쪽을 "공식"으로 할지는 대표님이 정해야 합니다.
  (이 환경에서는 두 주소 모두 접속이 막혀 실제 응답은 확인하지 못했습니다.)

**2. 크롤러 안내판 3종이 없다**
- `robots.txt` — AI 크롤러(GPTBot, ClaudeBot, PerplexityBot, Google-Extended 등)를 허용한다는 명시 + sitemap 위치
- `sitemap.xml` — 공개 페이지 7개(홈, 비즈홈, 앱 4, 신청)
- `llms.txt` — AI에게 "이 회사는 이런 곳, 핵심 페이지는 이것"을 요약해 주는 파일 (공식 표준은 아니지만 비용이 거의 0)
- **왜:** 없으면 "허용인지 모름" 상태. 새 사이트일수록 sitemap 유무가 발견 속도를 가른다.

**3. 비공개성 페이지가 공개돼 있다 — `신청폼/index.html`**
- "DiCA 명함 신청" 제작용 양식. title만 있고 `og`·`noindex` 없음 → 검색에 노출될 수 있음.
- **해결:** `<meta name="robots" content="noindex">` 추가 + robots.txt `Disallow: /신청폼/` (한글 경로는 `%EC%8B%A0%EC%B2%AD%ED%8F%BC` 도 함께).
  이 양식이 외부 고객에게 쓰이는 것이라면 링크 공유는 유지하되 색인만 막으면 됩니다.

### 🟠 P1 — AI가 "인용할 수 있는 형태"로 만들기

**4. 구조화 데이터(JSON-LD) 추가** — AI가 회사·상품·가격을 *문장 해석 없이* 읽게 해 줌
| 페이지 | 넣을 스키마 | 핵심 값 |
|---|---|---|
| 홈 | `Organization` + `WebSite` | name `TM LINK`, alternateName `["T.M Link","티엠링크"]`, founder 송승훈, 부산, sameAs(BNI Pioneer 등) |
| 비즈홈 | `Service` + `Offer` ×2 + `FAQPage` | 15만/25만원 KRW, 약 3일, "VAT 별도" |
| 앱 4개 | `SoftwareApplication` + `FAQPage` | 오토명함 무료/5,900원, 카드북, 만두 무료, 주주도사 |
| 각 페이지 | `BreadcrumbList` | 홈 › 앱 › 이름 |
- FAQ는 이미 본문에 있으므로 **같은 문구를 JSON-LD로 복제**만 하면 됩니다(문구가 다르면 감점).
- `apps/*/index.html` 은 **생성물** → `tools/apps-pages/regen.py` 템플릿에 넣어야 재생성해도 안 사라집니다.

**5. "정의 문장"이 첫 화면에 없다**
- AI는 페이지 맨 앞의 *"X는 Y를 위한 Z이다"* 문장을 잘 인용합니다.
- 홈 lead는 "TM LINK는 … 직접 만들고 운영합니다"로 좋지만 **누구를 위한지·어디인지**(부산, 개인 사업자)가 빠짐.
- 제안 (홈): *"TM LINK(티엠링크)는 부산의 앱 메이커 송승훈 대표가 운영하는 회사로, 1인 사업자를 위한 개인 브랜드 홈페이지 '비즈홈'과 디지털 명함·명함첩·통번역·AI 사주 앱을 만듭니다."*
- 비즈홈은 이미 강함: 가격표 + "평균 80만 원(크몽 2026-10)" 비교 + 출처 링크 — **AI 인용 1순위 재료**. 그대로 유지.

**6. 근거 부족(E-E-A-T)** — AI는 "누가, 얼마나 해봤나"를 봅니다.
- 현재: 대표 이름·BNI 소속만 있음. 제작 건수·업종·고객 후기·방문/저장 통계 **없음**.
- **해결:** 실제 수치가 있을 때만 추가(예: "제작 N건 · 업종 N개"). 추측 수치 금지(CLAUDE.md 원칙). 갤러리(BizHome-gallery) 링크는 이미 있으니 *건수*를 본문에 적는 것부터.

### 🟡 P2 — 마무리

**7. 이미지 alt 비어 있음** (앱 페이지 4곳) — 장식이면 `alt=""` 가 맞지만 `*-visual.jpg`는 제품 화면이므로 설명 추가. 비즈홈 샘플 이미지는 alt가 이미 좋음 ✅. (`regen.py` 수정)

**8. 공유 이미지** — `og.jpg` 1장을 전 페이지가 공유(비즈홈용). 홈·앱별 이미지는 CLAUDE.md "남은 일"에 이미 있음 → 그대로 진행.

**9. 영어·중국어·일본어 검색 노출** — 지금 언어 전환은 JS라 구글/AI는 **한국어만** 봅니다. 해외 바이어 타깃을 진짜 노릴 때만 `/en/` 정적 페이지 + `hreflang` 가 필요. *현 고객층(부산 BNI)에선 후순위.*

**10. 이름 표기 통일** — `TM LINK` / `T.M Link` / `T.M LINK` 혼용 → 기준표 6항대로 정리.

## ⚠️ 점검 중 발견한 별개 문제 (SEO 아님)

**주주도사 가격 불일치** — 공개 페이지(월 5,900/11,900/25,900 + 상담 횟수 표기) vs 원본 `content.py`(라이트 4,900/스탠다드 9,900, 횟수 미표기).
`regen.py` 실행 시 공개 페이지가 **옛 값으로 덮어써질 위험**. AI는 가격을 그대로 인용하므로 틀린 가격이 퍼지는 게 가장 나쁨 → 확정 후 원본부터 고칠 것.

## 실행 순서 제안 (효과 큰 순 · 합쳐서 약 1~2시간)

1. 대표 주소 확정 → canonical·og:url 통일 *(결정 필요)*
2. `robots.txt` · `sitemap.xml` · `llms.txt` 추가 + 신청폼 noindex
3. 홈·비즈홈·앱 JSON-LD (앱은 `regen.py` 템플릿에)
4. 홈 첫 문장을 "정의 문장"으로 교체
5. alt 보강, 후기·건수 수치 확보 후 추가

## 검증 방법 (적용 후)
- 구글 서치콘솔에서 sitemap 제출 + URL 검사 (이미 `googlef70cc7eda5131fbb.html` 인증 파일이 있어 등록은 돼 있을 가능성 큼)
- 리치 결과 테스트(search.google.com/test/rich-results)에 각 페이지 URL
- ChatGPT·Gemini·네이버에 "부산 개인 브랜드 홈페이지 제작 15만원", "디지털 명함 앱 오토명함" 직접 질문 → 인용 여부를 한 달 단위로 기록(기준선은 지금 한 번 찍어 둘 것)
